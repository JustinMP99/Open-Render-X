# Open-Render-X

This project is a cross platform 3D rendering engine using OpenGL, GLFW and glad

**Platforms currently supported:**
- MacOS
- Windows
- Linux

## Controls

**WASD** - Movement

**Q/E** - Up & Down

**Right Mouse** - Look Around

**1** - Open Debug Window

**Left Shift + 1** - Close Debug Window

**2** - Open Scene List

**Left Shift + 2** - Close Scene List
